# Tech Week Signup Agent Handoff

## Goal

Sign up for NYC Tech Week events that maximize:

- NYC local founder density

## Venue / Travel Caveats

- Home base is FiDi / Wall St.
- Downtown and near-downtown are preferred.
- Midtown is acceptable only for strong buyer fit.
- Several Partiful events hide the exact venue until RSVP. In the detailed calendar, those are marked as `approx_neighborhood_hidden`.
- Use `techweek_nyc_accolades_detailed_calendar.md` for current travel estimates. Transit estimates use current SubwayInfo.nyc route estimates and are not guaranteed for June 2026 service changes.

## Signup Behavior

- Do not double-book hard conflicts unless one event is invite/apply-only and uncertain.
- For public/open events, RSVP/register immediately.
- For apply/request-invite events, submit applications and leave them tentative.
- If an event has a secondary registration link in the description, complete that too. Example: `Software for Hardware` mentions Luma ticketing.
- After every successful RSVP/application, record status in a local notes file or spreadsheet with:
  - Event name
  - RSVP status: registered / applied / waitlisted / rejected / needs action
  - Account used
  - Any venue revealed
  - Any required next step
