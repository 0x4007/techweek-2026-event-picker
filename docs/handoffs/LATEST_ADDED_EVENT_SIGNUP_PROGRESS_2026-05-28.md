## Suggested Answers For Non-Standard Questions

- Data center ecosystem: choose the closest truthful option. If unsure, "Enterprise buyer / IT / procurement" or the closest operator/builder option is usually safest.
- Data center perspective: "Founder/operator building AI products and evaluating infrastructure constraints around compute, latency, and enterprise adoption."
- Who to meet: "AI infrastructure operators, compute providers, and enterprise leaders working on reliable agent infrastructure."
- Semiconductor lunch theme: "How supply-chain constraints and inference economics will shape practical AI infrastructure over the next few years."
- Commitment to attend: answer "Yes" only if you can actually attend.
- Marketing opt-in questions: answer "No" unless you personally want the updates.
- Photography/recording notice: answer "I agree" if you are comfortable attending under that notice.
- Dietary restrictions: answer truthfully; "None" is fine if true.
